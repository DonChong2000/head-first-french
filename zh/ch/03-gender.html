第 3 章

每個名詞都有陰陽性

桌子是「她」，床是「他」，為甚麼？沒有人答得出。

Mme Tremblay，女房東Voici le salon, voilà la cuisine, et là, une petite chambre calme. Il y a un balcon !

Ka-yan，禮貌地點頭很好。很棒。真不錯。

Mme TremblayIl y a aussi une table et un lit. Le loyer est de 950 $ par mois.

Ka-yan，心想慢著。La table，卻是 le lit？桌子哪一點像女的了？還有，為甚麼是「petite chambre」，又是「chambre calme」？同一句話，兩套規則。

Voici 和 voilà 都解作「這是 / 那是」。Il y a 解作「有」，也可以是「這裡有」。把它當成一整塊來記。

Ka-yan 剛剛撞上了每個初學者都害怕的東西：法語的名詞，不是陽性就是陰性。床、租金、窗戶，甚至一整幢大廈，每個名詞都暗暗貼了一張標籤，而這張標籤會牽動身邊的小詞。

這一章會教你這些小詞（冠詞）、跟著名詞變化的形容詞，還有它們的排列次序。學完之後，你不僅能看懂租屋廣告，還能挑出單位有甚麼問題。

閱讀測驗常常出現廣告、告示和租約，而 le、une 這類小詞，每一行都有。

規則 1：每個名詞不是陽性就是陰性

指人的時候，性別跟著那個人：le père 是父親，la mère 是母親。換成指物件，就全無規律可循。窗戶是陰性（la fenêtre），陽台是陽性（le balcon），從來沒有哪個委員會解釋過為甚麼。

不用去找背後的道理。記名詞時，要連冠詞一起記，當成一個詞來背。不是「table」，而是 la table。筆記和生字卡上，也一律這樣寫。

le lit陽性 la table陰性 le loyer陽性 la cuisine陰性

四個都按一下聽聽（「床、桌子、租金、廚房」）。床哪有半點陽剛之氣？但它就是陽性，沒有原因。

陰陽性是一套沒人要求過的型別系統（type system）。你的工作，就是記住每個變數的型別。

中文腦：冠詞就像法語的量詞

粵語說「一張枱」(zoeng1 toi2)、「一張床」(zoeng1 cong4)、「一隻狗」(zek3 gau2)、「一部車」(bou6 ce1)。普通話也一樣：「一張桌子」(yì zhāng zhuōzi)、「一隻狗」(yì zhī gǒu)。哪個名詞配哪個量詞，全是一個個學回來的，從來沒有人講過規則。

法語的 le / la 也是一回事：每個名詞配一個，只能逐個記。好消息是，法語只有兩種，不是一大堆。

動動腦

「床」要配哪個量詞？你怎麼知道的？你能向六歲小孩解釋這條規則嗎？解釋不來的話，就說明你早就靠不斷使用，學會了一套沒有規則的系統。學法語，也是同一個道理。

規則 2：那些小詞（冠詞）

英語有 the 和 a。法語也有這兩個功能，不過每個都有好幾種形態，而形態會告訴你名詞是陰是陽、是單是複。

陽性陰性複數（通用）
thele litla tableles lits, les tables
the，元音前l'appartementl'adresseles appartements
a / someun litune tabledes lits, des tables

L' 會把陰陽性藏起來

還記得第 1 章的省音嗎？在元音或啞音 h 前面，le 和 la 都縮成 l'。於是 l'appartement（陽性）和 l'adresse（陰性）看上去一模一樣，冠詞再也幫不上忙。這類詞，改用 un 或 une 來記：un appartement、une adresse。千萬別寫成「le appartement」，那是拼寫錯誤。

複數要聽前面的小詞，不是聽名詞

第 1 章說過，詞尾的 -s 不發音，所以 chambre 和 chambres 聽起來完全一樣。複數的訊息藏在 les 和 des 裡，還有它們後面的聯誦：本來沉默的 s，會變成「z」音冒出來。

un appartement"un-na-par-te-man" les appartements"lé-za-par-te-man" des appartements"dé-za-par-te-man"

讀出聲來的「z」，就是複數的標記。兩句都按一下聽：La chambre est petite. / Les chambres sont petites. 讀音有變的，只有 la / les 和 est / sont。考聽力時，要訓練耳朵抓住這些小詞，意思全靠它們傳達。

中文腦：複數不改名詞本身

「一張床」變「兩張床」(loeng5 zoeng1 cong4)，「床」本身完全沒有變。法語寫出來要加 -s，但聽不出來：lit 和 lits 讀音一樣。所以要靠前面的 le → les、un → des，來分單數和複數。

寫複數很簡單：加 -s 就行。以 -eau 結尾的名詞加 -x（un bureau → des bureaux），以 -al 結尾的則變成 -aux（un journal → des journaux）。-s 和 -x 都不發音，但 -al 變 -aux，是少數聽得出的複數：「jour-nal」變成「jour-no」。

留意，l'eau 和 l'ascenseur 完全看不出陰陽性。l'eau 是陰性（une eau），l'ascenseur 是陽性（un ascenseur）。這就是省音的代價。

甚麼時候用哪一個？大致和英語差不多：un / une 用來帶出新的東西，le / la 則指雙方都已經知道的東西。

Il y a une chambre. La chambre est petite.

法語跟英語有兩點不同。第一，法語幾乎一定要有冠詞，所以要說 J'ai une table，不能說「J'ai table」。第二，泛指一類東西時，法語用 le / la / les，英語卻甚麼都不加：J'aime les chats.（「我喜歡貓。」英語：I like cats.）Le loyer est cher à Vancouver.（「溫哥華的租金很貴。」英語：Rent is expensive in Vancouver.）

你早就懂了

英語從法語借了一大批住屋用語，所以不少名詞你不用學就認得：un appartement、une table、la cuisine（沒錯，就是 cuisine）、un balcon、le garage、la terrasse 和 le salon。

字面意思固然是現成的，但陰陽性卻沒有奉送，皆因英語早就丟棄了語法性別。所以冠詞也要一起抄下來。

小心！

租屋市場裡的三個「假朋友」（形似義異的詞，false friends）。

  • une chambre 是睡房（bedroom），不是英語的 chamber（大廳／密室）。（不過加拿大的下議院叫 la Chambre des communes，可見古義在渥太華還保留著。）
  • le loyer 是租金（rent）。它長得像英語的 lawyer（律師），卻毫無關係。律師是 un avocat 或 une avocate。
  • une location 是租賃／出租的物業（rental），不是「地點（location）」。法語的「地點」通常是 un endroit。（至於 la place，可以指空位、空間，也可以指市鎮廣場，要看上文。）

規則 3：表示「一些」（du、de la、de l'）

床可以數：一張床、兩張床。咖啡和空間卻不能數。遇到這類不可數的東西，法語要加上表示「一些」的詞，叫部分冠詞（partitive），同樣按陰陽性分。

陽性陰性元音前
du caféde la placede l'eau
du bruit（噪音）de la lumière（光線）de l'espace

逐個按下去聽。常見的用法有：Il y a de la place dans la cuisine.（「廚房有空位。」）Il y a du bruit dans la rue.、J'ai du café. 複數的話，你已經學過 des。

否定句之後（例如「沒有空位」），這幾個詞會縮成 de。這留到第 4 章，到時再學怎樣說「不」。

字尾線索：一張小抄，不是定律

陰陽性沒有規則可循。不過有些字尾，常常和某一個性別湊在一起，值得留意。把它們當作線索就好：大部分時候都準確，但確實會有例外。

字尾通常是例子例外
-tion陰性la location, la situation沒有值得記的例外
-té陰性la sécurité, la qualitél'été (陽性), le côté (陽性)
-ure陰性la facture, la serrure, la peinturele murmure (陽性)
-ette陰性la serviette, la baguette極少
-ence陰性la résidence, la différencele silence (陽性)
-ment陽性l'appartement, le logement, le déménagement沒有值得記的例外
-age陽性le chauffage, le garage, l'étagela plage, la page, l'image, la cage
-eau陽性le bureau, le rideau, le manteaul'eau (陰性), la peau (陰性)
-isme陽性le tourisme, l'optimisme沒有值得記的例外

看看最後一欄的 l'eau。它和 le bureau 一樣以 -eau 結尾，卻是陰性。所以這些線索只能退居次席，作參考用，不能凌駕於生字卡寫明的性別。

沒有任何提示字尾的詞（lit、table、loyer、balcon），就像擲毫子，一半一半。實在要猜就猜一個，事後再在筆記裡改正。

沒有蠢問題

陰陽性搞錯了會怎樣？
人家還是聽得懂。從來沒有人因為說了 le table 而租不到單位。在口試中，考官主要看能否聽懂你的表達。寫作考試就不同了：冠詞用錯、配合出錯，都算文法錯誤，一錯再錯就會扣分。
到底有沒有甚麼竅門？
有三個小竅門：1）名詞一定連冠詞一起記。2）留意上面的字尾線索。3）把名詞放進一個短語，配一個你能聽出變化的形容詞來背，例如 un petit lit / une petite table。耳朵記住聲音，比死記標籤牢固得多。
指人的名詞呢？
跟著那個人的性別走：un ami / une amie、un étudiant / une étudiante。有些名詞的字形完全不變，只換冠詞：un propriétaire / une propriétaire（男房東／女房東）、un locataire / une locataire（男租客／女租客）。
陰陽性會不會改變詞義？
少數詞會。le poste 是職位，la poste 是郵局。le tour 是一輪、一圈或一趟旅程，la tour 則是塔。當成兩個不同的詞來背就好。

規則 4：形容詞要和名詞配合

形容詞的陰陽性和單複數，要跟它修飾的名詞一致。字典收錄的詞形一律是陽性單數。變陰性要加 -e，變複數要加 -s。聽聽這個規律：

Le salon est grand.陽性：d 不發音 La cuisine est grande.陰性：d 醒過來了 Les fenêtres sont grandes.複數：從 les、sont 聽出來

這又是第 1 章那個招數。grand 的 d 本來不發音，加了 -e 就把它喚醒。陽性形式如果以不發音的輔音結尾，陰性形式就是你聽得出的：petit / petite、vert / verte、chaud / chaude。

配合（agreement）就是型別檢查器（type checker）：每一句都會執行一次，而且從不知倦。

有些字尾的變化多一點。以下是最常用的幾種：

類型陽性陰性變化

本來就以 -e 結尾calme, rouge, jeunecalme, rouge, jeune甚麼都不用加
-émeublé（附家具）meublée只是拼寫不同，聽不出來

變複數，就在陰性或陽性形式後面加 -s：grands、grandes。形容詞如果本來就以 -s 或 -x 結尾，就不用變：mauvais、lumineux。複數的 -s 不發音，下一句你大概已經猜到了：複數要從 les 和 sont 聽出來。

租屋廣告裡，常常見到 ancien 和 neuf。neuf 是全新的（une cuisine neuve），nouveau 則是對你來說新的。

規則 5：大部分形容詞放在名詞後面

英語把形容詞放前面：a quiet apartment。法語通常放後面：un appartement calme。顏色、國籍，還有大部分描述性的形容詞，都跟在名詞後面。

只有少數常用形容詞放在名詞前面。用 BAGS 來記：Beauty（美醜）、Age（年齡／新舊）、Goodness（好壞）、Size（大小）。

BAGS
beau, jolijeune, vieux, nouveaubon, mauvaisgrand, petit

un grand balconS：放前面 une petite cuisineS：放前面 un joli quartierB：放前面 un appartement calme放後面 un salon meublé放後面 un propriétaire canadien放後面

回頭看 Mme Tremblay 那句話：une petite chambre calme。Petite 屬於 BAGS，放前面；calme 不屬於，放後面。兩個形容詞，兩個位置。Ka-yan 感到困惑，不無道理；但她沒看錯，這背後的確有一套規律。

中文腦：形容詞在前面還是後面？

中文的形容詞一定在名詞前面：「一間細屋」(jat1 gaan1 sai3 uk1)，普通話「一套小公寓」(yí tào xiǎo gōngyù)。法語的 un petit appartement 和你的習慣一樣，但 un appartement calme（一間安靜的屋，普通話：一套安靜的公寓）就整個倒轉過來了。

放前面的形容詞很少，記住 BAGS 就夠。其餘的，一律放後面。

cher 也可以放在名詞前面，不過那時是「親愛的」的意思，例如 mon cher ami。表示「貴」的時候，一定放後面：un loyer cher。

小心！

C'est + 形容詞，永遠用陽性。評論整個情況、句中沒有指明名詞時，形容詞一律是陽性單數：Le loyer ? C'est cher ! · C'est petit, mais c'est calme.

一旦點明了是甚麼東西，形容詞就要跟它配合：La chambre est chère. / Elle est chère. 另外，c'est 後面如果接著名詞，形容詞也要和那個名詞配合：C'est une belle cuisine.

Au Québec

租屋，往往是你最先接觸魁北克法語的場合。

  • 單位按房間數量計算。un 3 1/2 讀作「un trois et demi」。那個 3 是廚房、客廳和睡房，浴室就是那個 1/2。4 1/2 通常代表多一間睡房。它是陽性，因為背後有一個沒說出口的 appartement 或 logement。
  • un logement（租來住的單位）是標準法語，但在魁北克的廣告裡特別常見：logement à louer。
  • le dépanneur，俗稱「the dép」，就是街角的便利店。營業到很晚，賣牛奶、薯片和彩票。
  • la job。魁北克口語常把這個詞當陰性：J'ai une bonne job. 在法國，同一個外來詞卻是陽性。考試時，請用 le travail 或 un emploi。

全部聽得懂就好。考試時，請用標準詞彙。

看看你現在能看出的文法：beau 3 1/2 是陽性，放在名詞前面（BAGS）；lumineux 放在名詞後面。inclus 用陽性，因為它同時涵蓋 le chauffage 和 l'eau chaude，陰陽混合就用陽性。

重點整理

  • 名詞不是陽性就是陰性，指東西時是任意的。名詞連冠詞一起記：la table、le lit。
  • 冠詞有點像中文的量詞：跟名詞成對出現，要一對一對地記。
  • 定冠詞：le / la / l' / les。不定冠詞：un / une / des。l' 會藏起陰陽性，這類詞改用 un 或 une 來記。
  • 複數的 -s 不發音。複數要從 les、des 和聯誦的「z」聽出來。
  • 不可數東西的「一些」：du café、de la place、de l'eau。
  • 字尾只是線索，不是定律：-tion、-té、-ure、-ette、-ence 通常是陰性；-ment、-age、-eau、-isme 通常是陽性。記住這幾個例外：la plage、la page、l'eau、la peau。
  • 形容詞要配合：陰性加 -e，複數加 -s。不發音的輔音在陰性形式裡醒過來。本來就以 -e 結尾的形容詞不變。
  • 留意這幾種變化：-eux/-euse、-if/-ive、-ien/-ienne、-er/-ère，以及不規則的 beau / bel / belle、nouveau / nouvel / nouvelle、vieux / vieil / vieille。
  • 大部分形容詞放名詞後面。BAGS（美醜、年齡／新舊、好壞、大小）放前面。
  • C'est cher !：c'est 後面如果只有形容詞，一律用陽性。
  • 假朋友：chambre 是睡房，loyer 是租金，location 是租賃。
