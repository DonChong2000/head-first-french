第 3 章

每個名詞都有陰陽性

一張桌子是「她」，一張床是「他」，而且沒有人能告訴你為什麼。

Mme Tremblay，女房東Voici le salon, voilà la cuisine, et là, une petite chambre calme. Il y a un balcon !

Ka-yan，禮貌地點頭太好了。真棒。非常不錯。

Mme TremblayIl y a aussi une table et un lit. Le loyer est de 950 $ par mois.

Ka-yan，心中暗想等等。La table 卻是 le lit？桌子哪裡像女性了？還有為什麼是「petite chambre」卻又是「chambre calme」？同一句話裡，居然有兩套不同的規則。

Voici 和 voilà 都是「這是 / 那是」的意思。Il y a 意思是「有」或「這裡有」。請把它當作一個整體記下來。

Ka-yan 剛剛碰上了所有初學者最害怕的東西：法語的每個名詞不是陽性就是陰性。一張床、一筆租金、一扇窗、整棟大樓。每個名詞都貼著一張隱形標籤，而這張標籤會改變它周圍的所有小詞。

這一章會為你介紹這些小詞（冠詞）、隨之配合改變的形容詞，以及它們的排列順序。學完這一章，你就能看懂租屋廣告，還能挑出這間公寓有甚麼毛病。

看懂廣告、告示和租約是閱讀測驗的重要部分，而像 le 和 une 這樣的小詞每一行都會出現。

規則 1：每個名詞不是陽性就是陰性

指人時，性別跟著人走：le père 是父親，la mère 是母親。但指物品時，完全是隨機的。窗戶是陰性（la fenêtre），陽台是陽性（le balcon），而且從來沒有任何語言委員會能解釋箇中緣由。

別去糾結背後的邏輯。記名詞時，請連同冠詞一起記，當作一個單詞來背。不要只背「table」，要背 la table。在筆記本和單詞卡上也一律這樣寫。

le lit陽性 la table陰性 le loyer陽性 la cuisine陰性

把這四個都點擊聽一遍（「床、桌子、租金、廚房」）。床本身哪有一點陽剛之氣？但它就是陽性，沒有理由。

性別就像一個根本沒人想要的型別系統（type system）。你的任務就是記住每個變數的型別。

中文腦：冠詞就像法語的量詞

粵語說「一張枱」(zoeng1 toi2)、「一張床」(zoeng1 cong4)、「一隻狗」(zek3 gau2)、「一部車」(bou6 ce1)。普通話也是這樣：「一張桌子」(yì zhāng zhuōzi)、「一隻狗」(yì zhī gǒu)。哪個名詞配哪個量詞，全是你一個個學回來的，從來沒有人跟你解釋過具體規則。

法語的 le / la 也是同一回事：每個名詞配一個，只能逐個記。好消息是法語只有兩種，不是一大堆。

動動腦

「床」要配哪個量詞？你怎麼知道的？你能向一個六歲小孩解釋其中的規則嗎？如果不能，說明你早已透過實際使用學會了一套毫無規律可循的系統。學法語也是同一個道理。

規則 2：那些小詞（冠詞）

英語有「the」和「a」。法語也有這兩種功能，但每一種都有好幾種形式，而這些形式會告訴你名詞的性別和單複數。

陽性陰性複數（兩者通用）
thele litla tableles lits, les tables
the，母音開頭前l'appartementl'adresseles appartements
a / someun litune tabledes lits, des tables

L' 會隱藏名詞的性別

還記得第一章學過的省音（elision）嗎？在母音或啞音 h 之前，le 和 la 都會縮合為 l'。因此 l'appartement（陽性）和 l'adresse（陰性）看起來一模一樣。這時冠詞就無法幫你辨別性別了，所以請改用 un 或 une 來記這些詞：un appartement、une adresse。千萬不要寫成「le appartement」，那是拼寫錯誤。

複數要靠前面那個小詞聽出來，而不是名詞本身

第一章講過，字尾的 -s 不發音。因此 chambre 和 chambres 聽起來完全一樣。複數的標誌藏在 les 和 des 裡，以及它們後面的連音中：原本沈默的 s 會化身為「z」音復活。

un appartement"un-na-par-te-man" les appartements"lé-za-par-te-man" des appartements"dé-za-par-te-man"

這個唸出來的「z」音就是複數的標誌。現在把兩句都點擊聽聽看：La chambre est petite. / Les chambres sont petites. 發音改變的只有 la / les 以及 est / sont。在聽力考試中，一定要訓練耳朵去捕捉這些微小的詞，因為語義全靠它們傳遞。

中文腦：複數不改名詞本身

「一張床」變成「兩張床」(loeng5 zoeng1 cong4)，「床」本身完全沒有變。法語寫出來時要加 -s，但聽不出來：lit 和 lits 的讀音完全一樣。所以必須依靠前面的 le → les、un → des 來區分單數與複數。

書寫複數很簡單：直接加上 -s。以 -eau 結尾的名詞加 -x（un bureau → des bureaux），以 -al 結尾的名詞則變成 -aux（un journal → des journaux）。-s 和 -x 都不發音，但 -al 變 -aux 是少數聽得出來的複數：「jour-nal」變成「jour-no」。

請注意，l'eau 和 l'ascenseur 完全沒有透露任何性別資訊。l'eau 是陰性（une eau），而 l'ascenseur 是陽性（un ascenseur）。這就是省音帶來的代價。

甚麼時候用哪一個？用法大致跟英語差不多：un / une 用來引出新事物，而 le / la 則指雙方都已知曉的事物。

Il y a une chambre. La chambre est petite.

有兩點跟英語不同。首先，法語幾乎無時無刻都需要冠詞，所以必須說 J'ai une table，絕不能說「J'ai table」。其次，法語在表達泛指概念時會使用 le / la / les，而英語此時則甚麼都不加：J'aime les chats.（「我喜歡貓。」/ 英語：I like cats.）Le loyer est cher à Vancouver.（「溫哥華的租金很貴。」/ 英語：Rent is expensive in Vancouver.）

要是 une clé 答錯了也別擔心。鑰匙就是鑰匙，直接記住它就行了。

你早就懂了

英語從法語借用了大量的住屋詞彙，所以許多名詞你早就免費學會了：un appartement、une table、la cuisine（沒錯，就是「cuisine」）、un balcon、le garage、la terrasse 以及 le salon。

詞義是免費送你的，但性別可沒有，因為英語把性別丟掉了。記得把冠詞也一併抄下來。

小心！

租屋市場的三大「假朋友」（偽同源詞，false friends）。

  • une chambre 是臥室（bedroom），而不是英語中的「chamber」（大廳／密室）。（不過加拿大下議院是 la Chambre des communes，所以古義依然在渥太華保留著。）
  • le loyer 是租金（rent）。它長得很像英語的「lawyer」（律師），但兩者毫無關係。你的律師是 un avocat 或 une avocate。
  • une location 是租賃 / 出租物（rental），而不是「地點（location）」。法語的「地點」通常是 un endroit。（而 la place 則指空位、空間或市鎮廣場，要看上下文決定。）

規則 3：表達「一些」（du、de la、de l'）

床是可以數的：一張床、兩張床。但咖啡或空間就不能數了。對於這些不可數的事物，法語需要加上表達「一些 / 部分」的詞，稱為部分冠詞（partitive）。它同樣遵循陰陽性的分類規則。

陽性陰性母音開頭前
du caféde la placede l'eau
du bruit（噪音）de la lumière（光線）de l'espace

把它們都點擊聽一遍。典型用法包括：Il y a de la place dans la cuisine.（「廚房裡有空間。」）Il y a du bruit dans la rue.、J'ai du café.。至於複數，你早就學過 des 了。

在否定句之後（例如「沒有任何空間」），這些詞會縮減為 de。那是第四章的內容，到時我們會學習如何說「不」。

字尾線索：這是一張小抄，不是鐵律

名詞性別沒有硬性規則。但有些字尾與某個性別的吻合度極高，非常值得看上一眼。請把它們當作線索。大部分時候它們很管用，但例外也是真實存在的。

-ure陰性la facture, la serrure, la peinturele murmure (陽性)

看看最後一欄的 l'eau。它跟 le bureau 一樣以 -eau 結尾，但它卻是陰性。這就是為什麼字尾線索只能當參考，單詞卡上標記的真實性別才是最重要的。

至於那些沒有任何提示字尾的單詞（lit、table、loyer、balcon），就跟擲硬幣沒兩樣。非猜不可就猜一個，之後再在筆記裡修正就好。

沒有蠢問題

如果我搞錯了性別會怎樣？
大家還是聽得懂你在說甚麼。從來沒有人會因為說了 le table 而租不到公寓。在口說考試中，考官主要在乎能不能跟上你的思路。在寫作考試中，用錯冠詞或配合錯誤算作語法錯誤，如果你一錯再錯，就會被扣分。
到底有沒有甚麼訣竅？
有三個小技巧：1）永遠連同冠詞一起記名詞。2）看一眼上面的字尾提示。3）把名詞放在簡短的短語裡背，並搭配一個你能聽出變化的形容詞，例如 un petit lit / une petite table。比起死記標籤，你的耳朵對聲音的記憶更牢固。
那指人的名詞呢？
性別跟著人的實際性別走：un ami / une amie、un étudiant / une étudiante。有些名詞本身形式完全不變，只變冠詞：un propriétaire / une propriétaire（男房東／女房東）、un locataire / une locataire（男房客／女房客）。
性別會不會改變單詞的意思？
對極少數單詞來說，確實會。le poste 是職位，la poste 是郵局。le tour 是輪次、轉圈或旅行，la tour 則是高塔。把它們當作兩個完全不同的單詞來背就好。

規則 4：形容詞要配合名詞

形容詞必須配合它所修飾名詞的性別和單複數。字典裡的原始形式是陽性單數。變成陰性要加 -e，變成複數要加 -s。仔細聽聽這個規律：

Le salon est grand.陽性：d 不發音 La cuisine est grande.陰性：d 甦醒發音 Les fenêtres sont grandes.複數：從 les 和 sont 聽出來

這又是第一章學過的技巧。grand 字尾的 d 原本不發音，加了 -e 之後就把它喚醒了。如果陽性形式以不發音的子音結尾，陰性形式往往是你能聽得出來的：petit / petite、vert / verte、chaud / chaude。

配合（agreement）就像型別檢查器（type checker）。它在每個句子裡默默運行，而且永遠不知疲倦。

有些字尾的變化會稍微多一點。以下是你最常用的幾種模式：

模式陽性陰性發生了甚麼變化

本身已以 -e 結尾calme, rouge, jeunecalme, rouge, jeune不需添加任何字母
-émeublé（附家具）meublée純拼寫變化，聽不出區別
-euxlumineux, spacieuxlumineuse, spacieusex 變成「z」的發音
-if / -factif, neuf（全新）active, neuvef 變成 v
-iencanadien, anciencanadienne, ancienne鼻母音變成實質的 n 音（見第一章）
-ercher, premierchère, première出現開音符（accent grave）
其他少數例外bon, mauvaisbonne, mauvaisen 變成實質的 n 音，s 發「z」音

至於複數，只要在陰性或陽性形式後加上 -s 即可：grands、grandes。若形容詞本身已經以 -s 或 -x 結尾，則保持原樣：mauvais、lumineux。複數的 -s 是不發音的，所以你大概已經猜到下一句話了：複數是從 les 和 sont 聽出來的。

ancien 和 neuf 常常出現在租屋廣告中。neuf 意思是全新（une cuisine neuve）。nouveau 則是對你而言是新的。

規則 5：大部分形容詞放在名詞後面

英語把形容詞放在前面：a quiet apartment。法語通常把它放在後面：un appartement calme。顏色、國籍以及大多數描述性形容詞都置於名詞之後。

只有少數常用的形容詞會放在名詞前面。把它們簡記為 BAGS：Beauty（美醜）、Age（年齡／新舊）、Goodness（好壞）、Size（大小）。

BAGS
beau, jolijeune, vieux, nouveaubon, mauvaisgrand, petit

un grand balconS：前 une petite cuisineS：前 un joli quartierB：前 un appartement calme後 un salon meublé後 un propriétaire canadien後

現在回頭看 Mme Tremblay 說的那句話：une petite chambre calme。Petite 屬於 BAGS 詞彙，所以放在前面；calme 則不屬於，所以放在後面。兩個形容詞，兩個不同位置。Ka-yan 的困惑很合情合理，但她猜得沒錯：這背後確實有一套系統。

中文腦：形容詞在前面還是後面？

中文的形容詞一定在名詞前面：「一間細屋」(jat1 gaan1 sai3 uk1)，普通話「一套小公寓」(yí tào xiǎo gōngyù)。法語的 un petit appartement 與你的習慣相同，但 un appartement calme（一間安靜的屋子，普通話：一套安靜的公寓）就完全顛倒過來了。

放在前面的形容詞很少，記住 BAGS 就夠了。其他的，一律放在名詞後面。

cher 也可以放在名詞前面，但那時它的意思是「親愛的」，例如 mon cher ami。若表示「昂貴」，則永遠放在名詞後面：un loyer cher。

小心！

C'est + 形容詞永遠保持陽性。當你評價整個情況、句子中沒有具體名詞時，形容詞一律保持陽性單數：Le loyer ? C'est cher ! · C'est petit, mais c'est calme.

一旦你指明了具體事物，形容詞就必須與之配合：La chambre est chère. / Elle est chère.。此外，在 c'est 後面若接著一個名詞，形容詞就必須配合該名詞：C'est une belle cuisine.。

Au Québec

租屋是你最先遇到魁北克法語的地方。

  • 公寓以房間數量計算。un 3 1/2 讀作「un trois et demi」。其中的 3 指的是廚房、客廳和臥室；衛浴則是那個 1/2。4 1/2 通常代表有第二間臥室。它是陽性，因為背後省略了未說出口的陽性名詞 appartement 或 logement。
  • un logement（出租住宅）是標準法語，但在魁北克的廣告裡隨處可見：logement à louer。
  • le dépanneur（常暱稱為「the dép」）是街角的便利商店。它營業到深夜，販售牛奶、洋芋片和彩券。
  • la job。魁北克口語中常常把這個詞當作陰性：J'ai une bonne job.。而在法國，這個英語借詞則是陽性。在考試中，請使用標準詞彙 le travail 或 un emploi。

這些你都要能聽懂、看懂。但在考試中，請堅持使用標準法語詞彙。

考試熱身：閱讀廣告

TEF Canada 和 TCF Canada 的閱讀考試包含像廣告這樣的簡短日常文字，並附有選擇題。你不需要逐字看懂，只需掃讀並找出題目所問的細節即可。點擊任何一行即可聆聽發音。

Appartement à louer : beau 3 1/2 lumineux dans le Plateau.
Cuisine moderne, petit balcon, chambre calme.
Chauffage et eau chaude inclus.
Loyer : 950 $ par mois.
Pas d'animaux.
Écrire à Mme Tremblay.

  1. 租金是多少？
  2. 臥室怎麼樣？
  3. 是否包含暖氣？
  4. 可以養貓嗎？
答案

1 950 $ par mois（每月）· 2 calme（安靜）· 3 inclus（包含）：是 · 4 Pas d'animaux（禁止寵物）：不可以

看看你現在能看懂的語法：beau 3 1/2 是陽性，並且置於名詞之前（符合 BAGS 規則）；lumineux 則置於名詞之後。inclus 採用陽性形式，因為它同時涵蓋了 le chauffage 和 l'eau chaude，而陰陽混合的群體一律採用陽性。

重點整理

  • 每個名詞不是陽性就是陰性，物品的性別完全是隨機的。請連同冠詞一起記名詞：la table、le lit。
  • 冠詞有點像中文的量詞：它與名詞搭配出現，你必須成對記憶。
  • 定冠詞：le / la / l' / les。不定冠詞：un / une / des。l' 會隱藏性別，所以請改用 un 或 une 來記這類詞。
  • 複數的 -s 不發音。複數是從 les、des 和連音「z」中聽出來的。
  • 不可數事物的「一些」：du café、de la place、de l'eau。
  • 字尾只是線索，不是鐵律：-tion、-té、-ure、-ette、-ence 通常是陰性；-ment、-age、-eau、-isme 通常是陽性。記住例外：la plage、la page、l'eau、la peau。
  • 形容詞要配合：陰性加 -e，複數加 -s。原本不發音的子音會在陰性中甦醒發音。本身已以 -e 結尾的形容詞則不變。
  • 注意詞尾變化模式：-eux/-euse、-if/-ive、-ien/-ienne、-er/-ère，以及不規則形式 beau / bel / belle、nouveau / nouvel / nouvelle、vieux / vieil / vieille。
  • 大多數形容詞放在名詞後面。BAGS（美醜、年齡／新舊、好壞、大小）放在前面。
  • C'est cher !：在 c'est 後面，單獨出現的形容詞一律保持陽性。
  • 假朋友（偽同源詞）：chambre 是臥室，loyer 是租金，location 是租賃／出租物。
